GITHUB UPLOAD

This is the complete SnakeGame Maven project folder.

To upload it to GitHub:
1. Extract the ZIP file.
2. Open the extracted SnakeGame folder.
3. Upload the CONTENTS of the SnakeGame folder to your GitHub repository (not the ZIP itself if you want GitHub to display the source files).
4. Keep pom.xml at the repository root and keep src/ with its existing folders.

To open in NetBeans: File > Open Project > select the SnakeGame folder.

The Maven project is configured for Java 21. The SQLite JDBC dependency is downloaded by Maven during the first build when internet access is available.
